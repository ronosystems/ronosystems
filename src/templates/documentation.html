Quick Start

New here? Follow these four steps and you'll be running in minutes:

  1. Create an account — visit /auth/register/ and confirm your email.
  2. Set up your company — name, currency, timezone, and logo under Settings → General / Branding.
  3. Add your first product — go to Inventory → Add Product.
  4. Make a sale — open POS, scan or search the product, and complete the sale.
Tip: Everything is multi-tenant — each company's data is fully isolated. You can manage multiple companies from one account.

Getting Started

After registering, you'll land on a guided setup wizard. It walks you through:

  • Company profile (name, address, tax ID)
  • Currency, timezone, and date format
  • Branding (logo, favicon, primary color)
  • Payment methods (M-Pesa STK, Paybill, Buy Goods, bank transfer)
  • Team invitations

You can skip the wizard and configure everything later under Settings from the dashboard.

Inventory

The inventory module lets you track stock across one or more locations. Each product can have variants, batches, and serial numbers.

  • Add products one-by-one or bulk import via CSV.
  • Set reorder points; get alerts when stock drops.
  • Transfer stock between locations.
  • Track cost, price, tax, and margin per product.
Recommended: enable low-stock alerts in Settings → Preferences so you never run out.

Sales & POS

The POS (Point of Sale) screen is designed for speed. It works on touch screens, barcode scanners, and standard keyboards.

  1. Open POS from the dashboard.
  2. Search or scan items — they're added to the cart instantly.
  3. Choose a payment method (cash, M-Pesa, card, bank).
  4. Complete the sale — the receipt is generated and stock is updated.

Sales can be voided within the same shift, or refunded later from the Sales report.

Payments

{{ system_name|default:"RonoSystems" }} supports several payment methods out of the box:

  • M-Pesa STK Push — customer enters PIN on their phone.
  • Buy Goods (Till) — customer pays to your till number.
  • Paybill — customer pays to a business number with an account reference.
  • Send Money — direct phone-to-phone transfer.
  • Bank Transfer — record or reconcile bank payments.
  • Card — via a connected gateway (Stripe, Flutterwave, etc.).
Note: Each method can be toggled on/off individually in Settings → Payment. Disabled methods won't appear at checkout.

Team & Roles

Invite team members and give them exactly the access they need. Roles include:

  • Owner — full access to everything, including billing.
  • Admin — everything except ownership transfer.
  • Manager — sales, inventory, and reports.
  • Cashier — POS access only.
  • Accountant — read-only financial access.

Every action is logged. You can audit who did what and when under Reports → Audit Log.

Reports

Over 30 built-in reports, including:

  • Daily / weekly / monthly sales
  • Profit & loss
  • Inventory valuation
  • Top-selling products
  • Employee performance
  • Tax summary (VAT / eTIMS)

Reports can be exported to CSV or PDF, and scheduled to be emailed to you daily or weekly.

API Reference

{{ system_name|default:"RonoSystems" }} exposes a REST API for integrations. Authentication is token-based:

  • Base URL: https://your-domain.com/api/
  • Auth header: Authorization: Token YOUR_API_KEY
  • All requests and responses are JSON
  • Rate limit: 60 requests/minute per key

Example — list products:

  • GET /api/products/ — returns a paginated list
  • POST /api/sales/ — create a new sale
  • GET /api/reports/sales/?from=2026-01-01&to=2026-01-31
API keys: generate and revoke keys under Settings → Preferences → API. Keep them secret — treat them like passwords.

Troubleshooting

Common issues and how to fix them:

  • Can't log in? Use the "Forgot password" link on the login page.
  • M-Pesa payment not received? Check the STK status in Payment Reports → Pending.
  • Stock levels wrong? Run Reports → Inventory → Recalculate Stock.
  • Page won't load? Clear your browser cache or try incognito mode.

If none of these help, contact support below.
